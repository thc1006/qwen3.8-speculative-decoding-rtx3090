steps differ.

----------------------------------------------------------------------------------------------------
INTERNAL YARDSTICK. `c` refitted from each pass alone, every pass using all prompts,
so this spread is NOT prompt sampling -- the bootstrap above already covers that. Each
arm-pass gets a fresh server (design.fresh_server_per_arm_per_pass), so it does bound
server startup, allocation and cache state.
  It is a LOWER BOUND on what separates the rungs, not an estimate of it. The three
  passes of a rung run minutes apart inside one invocation, on one thermal trajectory;
  the rungs here ran hours apart. Whatever drifts on the scale of hours is invisible
  to this yardstick, so clearing it is necessary and not sufficient.

  Q4_K_M       pass1: 0.4138  pass2: 0.4116  pass3: 0.4123

a two-point dose-response with no bf16 anchor -- suggestive at best, and phase_qsmall

VERDICT: the marginal costs differ, and by more than this instrument's own
  session-to-session drift. Everything about the speculative cycle is held except
  the target's quantization, so part of what a verified position costs moves with
  it. Direction and rough size still have to be checked against H2' by hand: that
  account is a different estimator and no derivation relates the two.
