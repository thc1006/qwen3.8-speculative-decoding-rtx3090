--- correction: the bandwidth lever is not clean ---
  At a fixed power cap, raising the memory clock takes power from the core, so core
  clock falls across the bandwidth sweep. A compute-elastic arm is penalised by that,
  which makes its measured bandwidth elasticity an under-estimate. Below, the core-
  clock contribution is estimated using each method's OWN compute elasticity (from the
  pw-lo -> stock interval) and removed.

  over bw-lo -> bw-hi:
    method             core MHz  measured  core term  corrected
    baseline      1799 ->  1759     0.751      0.130      0.881
    mtp-n3        1721 ->  1708     0.135      0.078      0.213
    mtp-n7        1740 ->  1728     0.115      0.066      0.182

  The correction raises every arm's bandwidth elasticity, baseline included, so
  the RATIO between them moves less than either figure does.

--- caveat: the compute intervals are not identical across methods ---
  Under the same power cap, different methods settle at different core clocks, because
  a bandwidth-heavy workload spends more of the budget on memory. Measured here:
    pw-vlo   baseline=387  mtp-n3=478  mtp-n7=525
    pw-lo    baseline=906  mtp-n3=1081  mtp-n7=1178
    stock    baseline=1785  mtp-n3=1716  mtp-n7=1732
  So an interval labelled 'pw-lo -> stock' spans a different clock range for each
  method. Since elasticity is regime-dependent (see the two compute intervals above),
  these comparisons are close but not exactly matched. The direction of the effect is
  far larger than this mismatch; the magnitudes should be read with it in mind.

POST-HOC REVIEW (added after the run, before publication)
====================================================================================================

Four checks that the run itself does not perform.

CONTROL A. The same prompt and method under different resource conditions must produce
identical text. Clock speed does not change arithmetic, so anything else varying would show up
here. Checked 225 (method, prompt, pass) groups across all five conditions: 0 differ.

CONTROL B. Acceptance must likewise be identical. Checked 150 groups: 0 differ.

Together these establish that the resource manipulation changed only speed. The comparison is
the same work performed at different rates, which is the assumption every elasticity here rests
on and is not otherwise verifiable.

STATE. All 45 arm-passes applied their declared condition and read it back with 0 mismatches.
The thermal gate reached its 60 C target on all 45, entry temperatures 55-60 C, waits 0-30 s,
0 timeouts.

CLOCK STABILITY. This is the one real weakness. Within-request SM clock spread, as
(mean - min) / mean:

    condition   baseline   mtp-n3   mtp-n7
    stock          1.4 %    2.2 %    2.2 %
    bw-lo          1.3 %    1.9 %    1.9 %
    bw-hi          1.5 %    2.3 %    2.0 %
    pw-lo         12.3 %   12.7 %    8.1 %
    pw-vlo        16.8 %   27.2 %   43.8 %

At 175 W the clock oscillates instead of settling, so the mean is a poor description of the
operating point there. Two things keep this from touching the conclusions.

First, where it is worst is where nothing is concluded. The pw-vlo -> pw-lo interval returns
~0.92 for all three methods, a null: under severe starvation everything is compute-limited and
the methods are indistinguishable. The headline discrimination lives on pw-lo -> stock and on
the bandwidth axis, where instability is 8-13 % and 1-2 % respectively.

Second, the headline survives changing the denominator. Recomputing pw-lo -> stock against the
minimum sustained clock instead of the mean:

                  mean clock        min clock
    baseline        0.491             0.419
    mtp-n3          0.843 (1.71x)     0.676 (1.61x)
    mtp-n7          0.857 (1.74x)     0.738 (1.76x)

The absolute figures move by 15-20 %; the ratio that carries the argument does not.

Worth noting on its own: the instability grows with speculation depth (16.8 / 27.2 / 43.8 % at
175 W). Speculative decoding bunches its compute into verify bursts, so against a tight power
cap the clock swings more. That was not designed for and is consistent with the same mechanism
everything else in this phase points at.
